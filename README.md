# MORE - Modelling Of Renewable Energy
 
## What is MORE?
MORE is a system simulation tool that uses data for local power generation from photovoltaics and
wind from an external website (PVGIS, photovoltaic geographical information system). Based on
this information, MORE lets you design and operate an energy system with the following features.
- Local renewable energy production
- Distribution of electricity to hydrogen production (and storage) or grid feed-in
- Using hydrogen for mobile applications based on a weekly driving cycle
- Using hydrogen for heat demand (application for buildings)

MORE is written in PYTHON, data export occurs as HTML page or *.csv files, data import from
*.csv files and text files.

__=> Check out the release at the right hand side of this webpage.__

MORE can be understood as an extension of the project SunDriver (see repository SunDriver here at Github).
In this sense, MORE is much more than SunDriver.
