plotResults

Plot results of the system simulation. 

* plotYear(dataPV, myres)
- Energy to electrolyser -> EnergyToH2.png
- Enery to grid -> EnergyToGrid.png
- Hydrogen production (cumulated, this would refer to unlimited tank and no consumption) -> H2Prod.png

* plotStat(myres)
- State of stationary storage (in kg) -> Tank.png
- State of car fueling (driving range in %), this indicates if there is enough hydrogen to drive -> Car.png
- Hydrogen overproduction (this is internal data, electrolyser needs to shut down because storage is full) - OverProd.png

Uwe Reimer, Emden, January 2026

240def writeCSV(dataHeat, dataTemp, dataPV, dataWind, myres):
241    # write data (shown in plots) to separate *.csv file
242    
243    """ myres    
244    [0] power for H2 generation / kWh
245    [1] electricity to grid / kWh
246    [2] charge in battery / kWh
247    [3] heating demand from hydro / kWh (this is full demand minus available PV+wind)
248    [4] produced H2 / kg
249    [5] demand H2 / kg (heating)  -> this is the same as [3] just in kg
250    [6] tank H2 stationary / kg
251    [7] H2 filled in car / kg
252    [8] H2 overproduction (cannot be stored) / kg
253    [9] additional heat demand (storage empty) / kWh
254    [10] Driving range of car / percent
255    [11] Heating by stored hydrogen / kW
256    [12] Heating by PV + wind / kW
257    """
258    
259    mx = len(dataPV) + 1
260    x = range(1, mx, 1) # number of hours
261    
262    myfile = 'PVpower' + '.csv'		# file name for output
263    y = dataPV
264    myout = open(myfile, 'w') 
265    i = 0
266    mytext = '# hours / PV power in kW \n'
267    while i < len(x):
268        mytext = mytext + '%.2f , %.2f \n' %(x[i], y[i])
269        i = i + 1
270    
271    myout.write(mytext)
272    myout.close()
273    
274    myfile = 'WindPower' + '.csv'		# file name for output
275    y = dataWind
276    myout = open(myfile, 'w') 
277    i = 0
278    mytext = '# hours / wind power in kW \n'
279    while i < len(x):
280        mytext = mytext + '%.2f , %.2f \n' %(x[i], y[i])
281        i = i + 1
282    
283    myout.write(mytext)
284    myout.close()
285    
286    myfile = 'EnergyToH2' + '.csv'		# file name for output
287    y = myres[0]
288    myout = open(myfile, 'w') 
289    i = 0
290    mytext = '# hours / energy to hydrogen in kWh \n'
291    while i < len(x):
292        mytext = mytext + '%.2f , %.2f \n' %(x[i], y[i])
293        i = i + 1
294    
295    myout.write(mytext)
296    myout.close()
297    
298    myfile = 'EnergyToGrid' + '.csv'		# file name for output
299    y = myres[1]
300    myout = open(myfile, 'w') 
301    i = 0
302    mytext = '# hours / energy to grid in kWh \n'
303    while i < len(x):
304        mytext = mytext + '%.2f , %.2f \n' %(x[i], y[i])
305        i = i + 1
306    
307    myout.write(mytext)
308    myout.close()
309    
310    myfile = 'Battery' + '.csv'		# file name for output
311    y = myres[2]
312    myout = open(myfile, 'w') 
313    i = 0
314    mytext = '# hours / Charge in battery in kWh \n'
315    while i < len(x):
316        mytext = mytext + '%.2f , %.2f \n' %(x[i], y[i])
317        i = i + 1
318    
319    myout.write(mytext)
320    myout.close()
321    
322    myfile = 'Tank' + '.csv'		# file name for output
323    y = myres[6]
324    myout = open(myfile, 'w') 
325    i = 0
326    mytext = '# hours / Hydrogen in stationary storage in kg \n'
327    while i < len(x):
328        mytext = mytext + '%.2f , %.2f \n' %(x[i], y[i])
329        i = i + 1
330    
331    myout.write(mytext)
332    myout.close()
333    
334    myfile = 'Car' + '.csv'		# file name for output
335    y = myres[10]
336    myout = open(myfile, 'w') 
337    i = 0
338    mytext = '# hours / Driving range of car in % \n'
339    while i < len(x):
340        mytext = mytext + '%.2f , %.2f \n' %(x[i], y[i])
341        i = i + 1
342    
343    myout.write(mytext)
344    myout.close()
345    
346    myfile = 'OwnHeat' + '.csv'
347    myout = open(myfile, 'w') 
348    
349    i = 0
350    mytext = '# hours / Temperature in °C / Heat demand in kWh / Heat from PV and wind in kWh / Heat from H2 combustion in kWh / Demand from external in kWh \n'
351    a = dataTemp
352    b = dataHeat
353    c = myres[12]
354    d = myres[11]
355    e = myres[9]
356    while i < len(x):
357        mytext = mytext + '%.2f , %.2f , %.2f , %.2f , %.2f , %.2f \n' %(x[i], a[i], b[i], c[i], d[i], e[i])
358        i = i + 1
359    
360    myout.write(mytext)
361    myout.close()
